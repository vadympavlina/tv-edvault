Час роботи телевізорів

Поза цим часом на екранах глибокий чорний. Телевізори підхоплюють зміни самі, протягом кількох хвилин.

Тиждень

    Доступ для збереження

    Зміни записуються у файл settings.json репозиторію на GitHub. Для цього потрібен токен, його вводять один раз, і він зберігається лише в цьому браузері.

    Як отримати токен
    1. Відкрийте GitHub → Fine-grained token.
    2. Repository access: Only select repositories → tv-edvault.
    3. Permissions → Repository → Contents: Read and write.
    4. Натисніть Generate token і вставте його сюди.

    Доступ збережено в цьому браузері.
