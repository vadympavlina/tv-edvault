# Розклад IT STEP на телевізорах

Статичний сайт для ТВ у холах: показує [розклад аудиторій](https://lb.itstep.org/schedule?rooms=186,189,192,134,92,89,67,1,4,3,68,9,8,66,10,7,6,75,73,70,5,69,72,78,81,180,175)
на весь екран і не дає телевізору заснути.

## Як це працює

1. **Заставка.** Анімований логотип (сходинки виростають, чоловічок стає на першу, з'являється «IT ACADEMY»)
   і кнопка **«Запустити розклад»**. Кнопка одразу у фокусі, тож достатньо натиснути **OK** на пульті.
2. **Розклад.** Сторінка lb.itstep.org відкривається на весь екран без жодного інтерфейсу поверх. Кожні 10 хвилин
   вона перезавантажується у фоні й підміняється лише після повного завантаження, тож екран не блимає.
   Якщо інтернет пропав, на екрані лишається останній завантажений розклад.
3. **Ніч (20:00–08:00).** Глибокий чорний екран (`#000`). Якщо натиснути будь-яку кнопку пульта, на 5 секунд
   тьмяно з'явиться годинник і «Розклад увімкнеться о 08:00». О 08:00 розклад вмикається сам.
4. **ТВ не засинає.** Wake Lock API, а як запасний варіант на старих ТВ — невидиме беззвучне відео, що грає по колу.
5. **Автозапуск.** Після першого натискання кнопки ТВ це запам'ятовує. Якщо зникне світло чи браузер перезапуститься,
   розклад стартує сам через 15 секунд (на кнопці видно відлік).

Час рахується за `Europe/Kyiv`, навіть якщо в телевізора неправильний часовий пояс.

## Налаштування

Значення за замовчуванням лежать у [`config.js`](config.js). Для окремого ТВ їх можна перевизначити в адресі:

| Параметр    | Приклад               | Що робить                                     |
|-------------|-----------------------|-----------------------------------------------|
| `rooms`     | `?rooms=186,189,192`  | інші аудиторії                                |
| `on`, `off` | `?on=07:30&off=21:00` | коли показувати розклад                       |
| `refresh`   | `?refresh=5`          | як часто оновлювати, хв (`0` вимикає)         |
| `autostart` | `?autostart=0`        | секунд до автозапуску (`0` вимикає)           |
| `tz`        | `?tz=Europe/Kyiv`     | часовий пояс                                  |
| `time`      | `?time=21:30`         | лише для перевірки: «підставити» поточний час |

## Публікація

Чистий HTML/CSS/JS без збірки. Кожен пуш у `main` публікується на GitHub Pages
(`.github/workflows/pages.yml`). Один раз треба увімкнути: **Settings → Pages → Source: GitHub Actions**.

Локально: `python3 -m http.server` і відкрити `http://localhost:8000`.

## Поради для ТВ

- Вимкніть у налаштуваннях ТВ енергозбереження, автовимкнення і заставку: браузер не може скасувати таймер
  самого телевізора.
- Якщо браузер ТВ уміє режим кіоску чи «стартову сторінку», вкажіть там адресу цього сайту.
- Розклад відкривається всередині `iframe`. Якщо lb.itstep.org забороняє вбудовування
  (`X-Frame-Options` / `frame-ancestors`), замість розкладу буде сторінка з помилкою. Тоді адміністратори
  lb.itstep.org мають дозволити домен цього сайту у `frame-ancestors`.
